# 练习5 常见错误总结

---

## 错误 1：ArrayList 泛型写错——装不进对象

### 错误代码

```java
ArrayList<String> list = new ArrayList<>();   // ← 泛型写的是 String！
list.add(new Hero("张无忌",20,"123"));        // ← 塞的是 Hero 对象，报错！
```

### 为什么报错？

`ArrayList<String>` 声明这个集合**只能装 String 类型**的元素。你往里面塞 `Hero` 对象，类型不匹配，编译器直接报错。

```
ArrayList<String>  →  只能装 String
ArrayList<Hero>    →  只能装 Hero
```

泛型就是集合的"门禁"，声明了什么类型就只能放什么类型。

### 正确写法

```java
ArrayList<Hero> list = new ArrayList<>();     // 泛型写 Hero
list.add(new Hero("张无忌",20,"123"));        // ✅ 类型匹配，不报错
```

> **记忆口诀：集合装谁，泛型就写谁。**

## 错误 2：transient 字段忘记加访问修饰符

### 问题代码

```java
private String name;        // private
private Integer level;      // private
transient String password;  // ❌ 没写 private，默认 package-private
```

### 为什么不好？

其他字段都是 `private`，唯独 `password` 没写，风格不统一。虽然不影响 transient 的效果，但保持一致性是好习惯。

### 正确写法

```java
private transient String password;  // ✅ private + transient 一起用
```

---

## 总结

| 错误 | 原因 | 解决 |
|------|------|------|
| `ArrayList<String>` 装 Hero 报错 | 泛型声明和实际类型不匹配 | `ArrayList<Hero>` |
| transient 漏写 private | 复制粘贴时漏了 | 加上 `private transient` |

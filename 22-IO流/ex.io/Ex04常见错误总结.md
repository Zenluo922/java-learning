# 练习4 常见错误总结

---

## 错误 1：输出流没关就开始读

### 错误代码

```java
OutputStreamWriter osw = new OutputStreamWriter(new FileOutputStream(path), "gbk");
osw.write("你好");

// ❌ osw 还没 close 就去读了！
InputStreamReader isr = new InputStreamReader(new FileInputStream(path), "gbk");
```

### 为什么不行？

`OutputStreamWriter` 内部有一个**缓冲区**，调用 `write()` 时数据只是写到了内存的缓冲区里，**还没有真正写到硬盘上的文件**。

只有调用 `close()`（或 `flush()`）时，缓冲区的数据才会被刷新（flush）到硬盘。

```
write("你好") → 数据在内存缓冲区 → close() → 数据刷到硬盘文件
                  ↑ 这时候去读文件，文件还是空的！
```

### 正确顺序

```java
// 1. 写
OutputStreamWriter osw = new OutputStreamWriter(new FileOutputStream(path), "gbk");
osw.write("你好");
osw.close();  // ← 必须先关！数据才真正写入文件

// 2. 读完再读
InputStreamReader isr = new InputStreamReader(new FileInputStream(path), "gbk");
// ...读取并打印
isr.close();
```

> **记忆口诀：写完关掉，再读。**

---

## 错误 2：read() 读了但没打印

### 错误代码

```java
isr.read();  // ❌ 读了一个字符，返回值没接收，也没打印
```

### 为什么不行？

`read()` 的返回值是**读到的字符的 int 值**，你不接收它、不打印它，就等于读了但白读。

正确写法：

```java
int data = isr.read();                    // 接收返回值
System.out.println((char) data);          // 转成 char 打印
```

或者一次读多个字符：

```java
char[] cbuf = new char[1024];
int len = isr.read(cbuf);                 // 读到字符数组
System.out.println(new String(cbuf, 0, len));  // 转成字符串打印
```

---

## 总结

| 错误 | 原因 | 解决 |
|------|------|------|
| 写了就读 | 数据在缓冲区，没关流就没写到硬盘 | 先 close 输出流，再读 |
| 读了不打印 | read() 返回值没接收也没输出 | 用变量接收 + System.out.println |
